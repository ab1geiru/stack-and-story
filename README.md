# Stack & Story

## Overview

Stack & Story is a journal/blog web app where users can document what they learned, especially about AWS Cloud and AI. It uses React + Vite for the frontend, Node.js + Express for the backend, and SQLite for local storage.

## Main Features

- Sign up and sign in.
- Create, edit, and delete your own journal posts.
- Comment on posts.
- Edit or delete your own comments.
- Post authors can remove comments from their own posts.
- Optional profile pictures.
- Account settings to add, change, or remove your profile picture.
- Search journal entries.
- Light and dark mode.
- Four AWS-focused example journal entries.

## Technology Stack

React, Vite, Node.js, Express, SQLite, and CSS Modules.

## Basic Setup

From the project folder, run:

```powershell
npm.cmd install
npm.cmd run dev
```

or

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Project Purpose

This project was created for the AWS Learning Club-UST Development Committee assessment to demonstrate basic full-stack web development skills.
